# 📊 Excel Sales & Profitability Dashboard

An interactive **Sales & Profitability Dashboard built in Microsoft Excel** to transform sales data into meaningful business insights.

The dashboard provides a clear overview of revenue, profit, orders, units sold, COGS, countries, regions, and sales channels.

## 📌 Dashboard Overview

The dashboard includes key business KPIs:

- 💰 Total Revenue: ₹645,223
- 📈 Total Gross Profit: ₹296,384
- 📦 Total Units Sold: 6,698
- 📊 Gross Profit Margin: 45.94%
- 🛒 Total Orders: 2,707
- 💵 COGS: ₹348,839

## 📈 Key Features

- Month-wise Revenue & Gross Profit analysis
- Top 5 Countries by Total Revenue
- Country-wise sales performance
- Region-wise revenue analysis
- Sales Channel performance
- Interactive Product Category filters
- Interactive Country filters
- Interactive Sales Channel filters
- Quarter-wise filtering
- KPI cards for quick performance analysis
- Data visualization through charts and graphs

## 🎯 Project Objective

The main objective of this project was to create an easy-to-understand **business dashboard** that helps users quickly identify sales performance, profitability, and revenue trends.

Instead of analyzing raw data manually, the dashboard presents important information in a visual and interactive format.
